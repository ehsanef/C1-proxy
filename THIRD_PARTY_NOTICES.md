# Third-Party Notices and Acknowledgements

C1 Proxy incorporates algorithms and protocols based on open public specifications and standards:

---

### 1. SHA-224 (RFC 3874)
- **Specification**: RFC 3874 ("A 224-bit One-way Hash Function: SHA-224") by R. Housley.
- **Implementation**: Clean, original, self-contained pure TypeScript implementation of the standard FIPS 180-2 SHA-224 initial values and padding specification.

### 2. Trojan Protocol Specification
- **Specification**: Trojan protocol open networking specification by GreaterFire.
- **Implementation**: Clean-room TypeScript parser and packet validator.

### 3. VLESS Protocol Specification
- **Specification**: VLESS protocol v0 open networking specification by V2Fly community.
- **Implementation**: Clean-room TypeScript parser, packet bounds validator, and response header builder.

### 4. Shadowsocks SIP007 AEAD
- **Specification**: Shadowsocks SIP007 AEAD specification by the Shadowsocks project contributors.
- **Implementation**: Web Crypto AES-GCM and HKDF-SHA1 subkey derivation.

### 5. ISO/IEC 18004 QR Code Matrix Standard
- **Specification**: International Standard ISO/IEC 18004 for Quick Response Code symbology.
- **Implementation**: Clean, original, self-contained pure TypeScript Reed-Solomon polynomial math and SVG matrix renderer. Zero third-party telemetry.
